DAP Library Manager - 사용 설명서
====================================

1. 프로그램 실행
----------------
Visual Studio에서 F5를 누르거나,
터미널에서 아래 명령어 실행:

  dotnet run --project src/DAPLibManager.UI/DAPLibManager.UI.csproj


2. 폴더 선택
-------------
1) 상단의 [Select Folder] 버튼 클릭
2) DAP가 연결된 드라이브 또는 음악 폴더 선택
   예: D:\MUSIC, E:\DAP\Music, F:\SD\Music 등
3) 선택한 폴더 경로가 버튼 오른쪽에 표시됨


3. 라이브러리 스캔
------------------
1) 폴더 선택 후 [Scan Library] 버튼 클릭
2) 스캔 중에는 버튼이 비활성화됨 ("Scanning..." 표시)
3) 스캔 완료 후 하단에 "N track(s) found." 메시지 표시
4) 트랙 목록이 아래 ListView에 표시됨


4. 트랙 목록 확인
-----------------
스캔 결과는 아래 4개 컬럼으로 표시됨:

  - Title    : 트랙 제목 (메타데이터 없으면 파일명)
  - Artist   : 아티스트 이름
  - Album    : 앨범 제목
  - Duration : 재생 시간 (hh:mm:ss 형식)


5. 지원 파일 형식
-----------------
  - .mp3
  - .flac
  - .m4a
  - .wav


6. 참고 사항
------------
- 하위 폴더까지 자동으로 재귀 탐색함
- 메타데이터가 없는 파일은 파일명을 Title로 사용
- 파일을 읽을 수 없는 경우 해당 파일은 목록에서 제외됨
- 대용량 라이브러리는 스캔에 다소 시간이 걸릴 수 있음
